Built using 11ty

To run book exports:
npm run export
    - Updates books from spreadsheet

npm run exportAll
    - Exports everything
npm run exportTrivia
    - Exports Trivia
npm run exportWords
    - Exports exportWords
npm run exportLists
    - Exports exportLists
npm run exportInventory
    - Exports exportInventory

To test locally:
npm run dev
