The best “court-intrigue” fantasy I have ever read. Very impressive considering it was written in the 80’s, and it has me very excited to read more into the riftwar cycle. I hadn’t actually realized that this trilogy and the Magician trilogy are set in the same universe. It is true that it is a little too classic fantasy in that Mara is a bit too clever and all her plans seem to work out perfectly, but it was a good book.
