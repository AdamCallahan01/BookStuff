I got this in June. This was amazing. I bought the book a while ago, but kept hearing more and more about it as time went on and so I read it. It took me a while to get really hooked, but once I was I flew through it. Narrative style is the main character telling his life story, giving us clues about the present and future (like Name of the Wind), but done perfectly. The only way this could be better is if a little bit more went right for Hadrian, like he is always a little sad.
