So much nothing happened for the majority of this book. We followed a lot of characters and events that I did not really care about, and only got glimpses of the interesting stuff. But, the last 10% was the best this series has been since the first book. I actually feel excited going into the final book which I did not think I would be at any point until the last chunk. A lot of the politics feel pretty bland but again they did finally start to heat up in the back half and kept getting better. Plus we covered Ashia’s backstory, which felt super pointless, I think he was just trying to stick to the same scheme we have seen in each book up to this point. If this one got edited and trimmed down heavily it actually could have been a solid entry, but we’ll see how the final book closes it out. The overarching plot and story still has interest, just so many smaller things that need to be fixed.
