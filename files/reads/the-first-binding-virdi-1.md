Long book. Very derivative of The Name of the Wind, and certain parts were so similar I found myself waiting for a certain character or event that I knew would be coming. However it is still a very well written story and has some interesting and important differences. The narrator’s female voices took a good bit of getting used to and along with the already slow start to the book it took me a long time to get invested in it, but around the halfway mark I really started enjoying it.
2026: Still not sure if this is just plagiarism
