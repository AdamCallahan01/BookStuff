Narrated by Steven Pacey, which is an automatic advantage. Could just be the narrator but did feel vaguely Abercrombie-esque. This is a great book that more people should read. Set in a similar historical world to when Europeans first crossed the Atlantic and clashed with the Native Americans, but definitely not a historical fantasy. Great flintlock fantasy and, while not super complex, an enjoyable magic system with good rules. The characters are great and varied. This book rocks. Saw some praire dogs while listening.
